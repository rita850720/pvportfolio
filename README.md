# Pharmacovigilance Evidence Portfolio

Public portfolio for Rita Rui-Ci Lin, PhD, presenting independent safety-surveillance case studies based on FDA labeling, regulatory history, safety communications, and openFDA FAERS/AEMS data.

## Pages

- Home
- Safety surveillance case studies
- Literature surveillance framework
- Reproducible methodology
- Professional background

## Local preview

Open `index.html` directly, or serve the folder with a local static web server.

## GitHub Pages

In repository settings, choose **Pages**, then deploy from the `main` branch and the repository root.

## Scope

These are independent educational projects based on public information. They are not affiliated with or endorsed by FDA, any employer, or a product manufacturer. The analyses do not provide medical advice and do not establish incidence or causality.
